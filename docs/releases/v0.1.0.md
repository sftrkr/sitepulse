# sitepulse v0.1.0 Release Notes

`sitepulse` v0.1.0 is the first public release of the sitemap health checker and AI agent readiness audit CLI.

## Highlights

- Sitemap URL discovery with sitemap index and gzip sitemap support.
- Concurrent URL health checks with timeout, retries, redirect tracking, GET/HEAD support, and response timing.
- CSV, JSON, HTML, JUnit XML, and SARIF exports.
- Metadata extraction for title, meta description, and canonical URL.
- robots.txt filtering, same-host filtering, max URL limits, custom User-Agent, and politeness controls.
- AI agent readiness audit with checks for `llms.txt`, crawler access rules, discovery headers, protocol discovery, JSON-LD, DNS-AID, and agentic commerce signals.
- JSON config file support for repeatable audits.
- GitHub Actions CI and release workflows.

## Install

Install from the release tag:

```bash
cargo install --git https://github.com/sftrkr/sitepulse.git --tag v0.1.0
```

Or download a prebuilt binary from the GitHub Release once release assets are published.

## Basic usage

```bash
sitepulse check https://example.com/sitemap.xml
```

## Agent readiness audit

```bash
sitepulse check https://example.com/sitemap.xml --agent-ready
```

## CI usage

```bash
sitepulse check https://example.com/sitemap.xml \
  --fail-on-errors \
  --export-junit report.xml \
  --export-sarif report.sarif
```

## Notes

This is a `0.1.0` release. Some agent-readiness standards are still emerging, so checks may evolve in future releases.
