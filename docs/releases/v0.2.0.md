# sitepulse v0.2.0 Release Notes

`sitepulse` v0.2.0 expands the initial release with stronger CI integration, standalone agent readiness audits, stricter config validation, and safer large-site scanning controls.

## Highlights

- New standalone `sitepulse agent-ready <SITE_URL>` command.
- New `sitepulse config validate <FILE>` command.
- JSON config schema and example config.
- JUnit XML and SARIF exports for CI systems.
- Dry-run discovery mode for large sitemap planning.
- Summary-only, quiet, no-color, slow-threshold, and only-slow terminal output controls.
- Configurable redirect limits, custom User-Agent, request delay, global rate limits, per-host concurrency, and per-host rate limits.
- Improved JSON-LD schema type reporting in agent readiness audits.
- Expanded documentation for usage, CI, configuration, exports, and agent readiness.

## Install

```bash
cargo install --git https://github.com/sftrkr/sitepulse.git --tag v0.2.0
```

Or download a prebuilt binary from the GitHub Release once release assets are published.

## Examples

```bash
sitepulse check https://example.com/sitemap.xml --summary-only --fail-on-errors
```

```bash
sitepulse agent-ready https://example.com --fail-under 80
```

```bash
sitepulse config validate examples/sitepulse.json
```
