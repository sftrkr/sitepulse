# sitepulse v0.3.0 Release Notes

`sitepulse` v0.3.0 focuses on MCP support, making the project usable by Codex-compatible apps and other MCP-capable AI clients as a local site intelligence server.

## Highlights

- New `sitepulse mcp` stdio MCP server.
- MCP tools: `check_sitemap`, `agent_ready`, and `validate_config`.
- MCP startup connection information with a Codex-compatible config snippet.
- MCP export path safety via `--export-root` and `--allow-absolute-export-paths`.
- MCP `check_sitemap` support for config files, dry-run, exports, fail-on-errors, rate limits, and per-host controls.
- Expanded MCP documentation and integration tests.
- README and package metadata updated to describe the MCP-enabled scope.

## Install

```bash
cargo install --git https://github.com/sftrkr/sitepulse.git --tag v0.3.0
```

Or download a prebuilt binary from the GitHub Release.

## MCP usage

```bash
sitepulse mcp
```

Codex-compatible local MCP config:

```json
{
  "mcpServers": {
    "sitepulse": {
      "command": "sitepulse",
      "args": ["mcp"]
    }
  }
}
```

## Safety note

MCP export paths are relative by default and path traversal with `..` is rejected. Use `--export-root` to restrict MCP exports to a specific directory.
